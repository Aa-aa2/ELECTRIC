
# ⚡ ELECTRIC — CHEW. MOVE. GO.

ELECTRIC is a sports-fuel brand website focused on drinks, snacks, and ideas designed for people who love to move.

## 🚀 Features

- ⚡ ELECTRIC branding
- 🥤 ELECTRIC Drink
- 🍬 ELECTRIC BITES
- 🍫 ELECTRIC P-BAR
- 💡 Customer idea suggestion section
- 📌 Pinned idea box
- 📱 Responsive design
- 🎨 Sporty blue and green design
- 🪟 Product information pop-ups

## 🛠️ Built With

- HTML
- CSS
- JavaScript

Visitors can submit ideas for new ELECTRIC products, flavours, snacks, drinks, and more.
